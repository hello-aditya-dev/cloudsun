# CloudSun Dental — Production Requirements

## Technical requirements

- Real telephone provider (Twilio or compatible)
- Real AI provider for live agent behaviour
- Real Gmail/Outlook, WhatsApp Business, Google/Microsoft Calendar credentials
- Real dental practice-management system connector
- Real authentication (NextAuth with OAuth)
- Real database (PostgreSQL via Prisma)
- Real payment processing
- Real SMS delivery

## Legal and compliance requirements

- HIPAA compliance review (US)
- GDPR compliance review (EU)
- DPDP compliance review (India)
- Business Associate Agreement (BAA) where required
- Data processing agreements
- Patient consent management
- Data retention policies
- Audit log retention

## Security requirements

- Role-based access control
- Two-factor authentication
- SSO for enterprise
- IP allowlist
- PII masking
- Call recording consent
- Data location controls
- Encryption at rest and in transit

## Integration requirements

- Dental PMS: Dentrix, Open Dental, Eaglesoft, Curve Dental, CareStack, Denticon
- Communication: Twilio, Gmail, Outlook, WhatsApp Business
- Calendar: Google Calendar, Microsoft Calendar
- Payments: Payment provider, financing provider
- Forms: Patient forms provider

## Current status

None of the above are currently implemented. CloudSun Dental is an interactive product prototype.
